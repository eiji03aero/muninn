# mn-regen-moc: MOC再生成＋壊れリンク検出

CLAUDE.md の規約（命名・リンク・タグ・コミット運用）に必ず従うこと。MOCは `notes/` からいつでも再生成できる派生物であり、作り直してよい。

## 手順

1. **走査**: `notes/` 全体の frontmatter（`tags:`）と本文の `[[リンク]]` を Grep で収集する。
2. **MOC再生成**: テーマごと（おおむねタグの第1階層ごと）にMOCを作成・更新する。
   - MOCはノートの単純な羅列にしない。ノート間の関係が分かる短い説明を添える。
   - ノートが1〜2枚しかないテーマはMOCを作らず `home.md` 直下に置く。
3. **home更新**: `moc/home.md` に全MOCへのリンクを載せ、全MOCに到達できることを保証する。どのMOCにも属さない孤児ノートは「未分類」に列挙する。
4. **壊れリンク検出**: 存在しないノートへの `[[リンク]]` を検出する。
   - 明らかなファイル名の打ち間違い・リネーム漏れは修正する。
   - 「まだ書かれていないノート」へのリンクは壊れではない。サマリで「未作成ノート候補」として報告する。
5. **コミット＆プッシュ**: push する前にまず `git fetch origin` でローカルの `main` を remote の最新に更新（`git pull --rebase origin main` 等）し、その最新の `main` にコミット（別ブランチで作業した場合は `main` にマージ）してからpushする。
6. **サマリ報告**: 「作成・更新したMOC / 修正した壊れリンク / 孤児ノート / 未作成ノート候補」を報告する。
