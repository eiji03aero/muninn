# mn-research: 調査→原子化→記録

CLAUDE.md の規約（命名・原子化・リンク・タグ・コミット運用）に必ず従うこと。

## 手順

1. **調査**: 依頼内容を調査する（WebSearch / WebFetch 等）。一次情報を優先する。
2. **原子化設計**: 書き始める前に、調査結果を1ノート1アイデアに分割する計画を立てる。
   - 作るノートの一覧（ファイル名・タイトル）
   - 各ノートのタグ（既存タグを Grep で走査してから決める）
   - ノート間および既存ノートとのリンク
   - 更新が必要なMOC
3. **重複チェック**: 既存の `notes/` を走査（Grep で title / tags）し、同じアイデアのノートがあれば新規作成せず統合する。
4. **ノート作成**: `templates/note.md` に従って `notes/` に作成。
   - 要約は自分（ユーザー）の言葉で書く。原文の丸写しをしない。
   - 出典がある場合は本文末尾に `## Sources` セクションを設けてURLを残す。
5. **逆リンク**: 関連する既存ノート側にも逆方向の `[[リンク]]` を追記する。
6. **MOC更新**: 該当するMOCを更新（なければ作成を検討）。`moc/home.md` から全MOCに到達できることを確認。
7. **コミット**: mainに意味のある単位でコミットしてpushする。既存ノートを変更・統合した場合は理由をコミットメッセージに明記。
8. **サマリ報告**: 「作成したノート一覧 / 統合・変更した既存ノート / 新設したタグ・MOC / 判断に迷った点」を報告する。人間はこれと `git show` で事後レビューする。

## 注意

- 調査結果を `inbox.md` に書き出さない。このskillは「文脈が一番濃いその場で原子化する」ための直接ルート。
- 調査が長大な場合も原子化を妥協しない。10ノートになるなら10ノート作る。
