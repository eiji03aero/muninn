ソールの刻印は **H3 / 19**。

**2026-10-02 に実測**：総 **199.2y** / キャリー186.4 / ボール初速55.1 / HS39.4 / ミート1.40 / 打ち出し13.5° / バックスピン3337 / サイドスピン−667。自己申告の帯（180〜200y）の**上端**に出た。

> ※シミュレーター（GOLF NAVI）の画面表示は「3 Iron」。これは**選択肢にユーティリティが無いため、3Iで代用している**ため（2026-10-02 に本人確認済み）。以後このシミュレーターで3Uを打つと必ず「3 Iron」と表示される。**計測値そのものは実測なので影響しない**が、画面のクラブ名は信用しないこと。

**ミート1.40はこの日の3本で最も高い**（1W 1.37 / 5I 1.29）。「振るイメージが定着しない」と感じている番手だが、**接触の効率はバッグで一番良い**。感覚と数字が食い違っている。

「振るイメージが定着しない」と感じている番手。3番アイアンをUT化した経緯のクラブでもある。

## 解説

**JGR は TOUR B の中でも「やさしさ・飛距離」側のライン**で、ツアー向けの TOUR B X（小ぶり・操作性）とは設計思想が逆。HY（ハイブリッド）はその中でも、ロングアイアンの代替として**上がりやすさと直進性**を最大化した設計になる。写真のヘッドは投影面積が大きく、ソールも広い。

**本来の見せ場は「ロングアイアンでは上がらない人が、同じ距離を高い球で運べること」**。それを成立させている仕組みが3つある。

1. **低く深い重心**。ヘッド後方に重量を配すると打ち出しが上がり、ロフト19°でもボールが浮く。同ロフトのアイアン（3番相当）より明確に高く飛ぶ。
2. **高いMOI（慣性モーメント）**。ヘッドが大きく重心が深いぶん、打点が外れてもフェースがブレにくい。**ミスの損失を減らす**のがこのクラブの本体価値。
3. **ワイドソールと丸み**。芝に刺さらず滑る。多少ダフっても抜けてくれる。

ここで押さえたいのは、**この3つはどれも「ミスの損失を減らす」機能であって、「操作に応えてくれる」機能ではない**こと。やさしいクラブは、振り手の操作を代行してはくれない。むしろ逆で、**MOIが高いクラブほど、手で当てにいく微調整は効かない**（フェースが返りにくいのではなく、返りの慣性が大きく、手の小さな入力では変わらない）。ブレードで無意識にやっている補正が、このクラブでは過剰入力として残る。

**自分の持病との相性**：ハイブリッドは総じてオフセットがあり、つかまり寄りの設計。自分は**フック・返して左**の持病なので、**手で返す動作とクラブの設計が足し算になって左に出る**リスクがある。ドライバーのステルスHDとまったく同じ構図。ここでの正しい目的語は「操作をやめる」ではなく **「手で返さない・体で回す」**。

**「イメージが定着しない」ことの仮説**。3つ考えられる。
- **見た目がウッドで、要求はアイアン**。ヘッド形状が「すくう・払い上げる」動作を呼ぶのに、地面から打つ以上は**最下点がボールの直後＝ボールファースト**でなければならない。この認知の不一致がハイブリッドが難しいと言われる主因。→ [[golf-club-length-gradient-longer-shallower-flatter-ball-forward]]
- **球数が少ない**。7番と違って練習で打つ機会が少なければ、そもそも定着しない。
- **担当範囲が広すぎる**。このセットでは3Uが**ドライバー（276y）と3番アイアン（推定165y前後）の間**をひとりで埋めている。180〜200yの20y幅は「狙いがブレている」のではなく「**このクラブで複数の距離を打とうとしている**」結果かもしれない。

**次に確かめる観点**：まず**シャフトのスペック**（刻印を見る）。JGR HY の純正はカーボンで、フレックスによって振り感がかなり変わる。次に**同条件で5球打って距離の散らばりを見る**——180〜200の20yが、打点のバラつきなのか、意図的な打ち分けなのかで対処がまったく違う。
