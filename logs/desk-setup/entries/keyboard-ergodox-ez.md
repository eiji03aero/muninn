メインのキーボード。右隣に Magic Trackpad を置いている。

## 解説

**何者か**。ErgoDox はもともとオープンソースで設計された自作向けの分割キーボードで、それを完成品として売り出したのが ZSA の **ErgoDox EZ**（2015年のクラウドファンディング発）。特徴は3つある。

1. **完全な左右分割**。左右を肩幅に離して置ける。
2. **格子配列（列ごとに縦にずらした配置）＋親指クラスタ**。指の長さに合わせて列を揃え、普段ほとんど仕事をしない親指に Enter や Space、修飾キーを持たせる。
3. **QMK ファームウェア**で、レイヤーやキー配置を自由に書き換えられる（ZSA の Oryx という設定ツールもある）。

**本来の見せ場**。分割キーボードの狙いは、**手首を内側に折らずに、肩幅で、胸を開いた姿勢のまま打てる**こと。一体型キーボードは両手を身体の中央に寄せるので、手首が小指側に折れ（尺屈）、肩も内に入る。さらに ErgoDox EZ は別売りのチルト/テントキットで**内側を持ち上げる（テンティング）**こともでき、前腕のねじれ（回内）を減らせる。分割しただけで真っ平らに置くと、効果は半分くらいにとどまる。

**今の使い方で気になること（仮説）**。トラックパッドを**キーボードの右外**に置いている。分割キーボードの隠れた利点は、**左右の間（身体の正中）が空くこと**で、そこにトラックパッドを置けば右手を外へ伸ばさずに済む。右外に置くと、マウス操作のたびに右腕が外へ開き、肩が軽く外転した状態が繰り返される。今の置き方が悪いとは限らないが、分割キーボードを持っているなら「真ん中置き」は試す価値のある1手。

**机上に置いていることの帰結**。キーボードを机に置くと、**机の高さは肘の高さで決まる**（肘をほぼ直角にして、前腕が机と水平になる高さ）。机の高さが肘で決まると、机に載せた画面の高さも道連れで決まってしまうので、画面は**スタンドやアームで個別に**目の高さへ合わせることになる（→ [[desk-and-forearm]]）。つまり、このキーボードの置き場所が、デスク全体の高さ設計の起点になっている。

**次に確かめる観点**
- 机の高さが肘の高さに合っているか（肩がすくんでいないか）
- テンティングしているか（チルト/テントキットの有無）
- 左右の間隔と、トラックパッドの位置
