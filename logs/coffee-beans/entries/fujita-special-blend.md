ペーパードリップ。

淹れた感じ、見た目にはとくに特徴は見られず。**表記の通りの苦味とコクのありそうな、黒味と芯の通ってそうな見た目。**

**酸味控えめ、苦味も強すぎず、喉越しのコクがしっかりある感じ。** ドリップが上達したからか、**特徴をクリアに感じられている**気がする。豆の性質とか鮮度もあるかもだが。

うむ。**かなり好みのチョコ系の甘味と苦味とコクのコーヒー。** 安かったのでこれはレギュラーかな。

（粉270g・中挽き。賞味期限 27.06.20／生豆生産国名 **ベトナム、エチオピア**）

## 解説

**この豆が何者か。** 藤田珈琲は1963年創業、大阪・東大阪市の焙煎会社。家庭用レギュラーコーヒーの製造販売が本業で、**業務スーパーやドン・キホーテなどに手頃な価格帯で卸している**。日本最大級の焙煎機を備えた奈良結崎工場（この袋の製造所）と、小ロット対応の大阪高井田工場の2拠点体制。「安かったのでこれはレギュラー」というあなたの判断は、**まさにこの会社が狙っている買われ方**にあたる。

**本来はどう楽しむ豆なのか。** 袋のレーダーチャート（5軸・4段階）がはっきり答えを書いている。

| 軸 | 表示 |
|---|---|
| **にがみ** | **4**（最大・外周に到達） |
| コク | 3 |
| 香り | 3 |
| 甘み | 2〜3 |
| **酸味** | **1未満**（最小） |

**にがみが振り切れていて、酸味がほぼゼロ。** キャッチの「深い味わいとコク」そのままで、**苦味・コク・甘みの三角形で聴かせる設計**。酸を最初から捨てている。

**そして今回いちばんの発見は、この形が生豆生産国名の並びから読めること。** 袋の表示は **「ベトナム、エチオピア」**。実は**レギュラーコーヒーの生豆生産国名は、公正競争規約で配合比率の多い順に並べる**と決まっている（重量1位の原産地表示は食品表示法で2022年4月から完全義務化）。つまり**この袋はベトナムが主役**だと明言している。

- **ベトナム（主役）** = ロブスタの世界一の産地。**苦味とボディを担当** → にがみ4・コク3
- **エチオピア（脇）** = 華やかな香りの担当 → 香り3
- **酸味が1未満** = ロブスタ主体なら当然。エチオピアも脇役の比率では酸を立てるに至らない

**2カ国だけの構成が、そのままチャートの形になっている。** これまでのUCC（ブラジル、ベトナム他）やハマヤ（ブラジル、ベトナム他）は**ブラジルが先頭＝土台がブラジル**だったのに対し、今回は**ベトナムが先頭＝土台がロブスタ**。同じ2カ国でも順番が逆なら別の設計、ということが記録帖の中で初めて並んで見えた。

**あなたの所見は、このチャートとほぼ一致している。** 「酸味控えめ」（酸味1）、「喉越しのコクがしっかり」（コク3）、「チョコ系の甘味と苦味」（にがみ4＋甘み2〜3）。**見た目の「黒味と芯の通ってそうな感じ」を飲む前に言い当てていた**のも、中深煎りの外観としてきれいに整合している。

**ただし1点だけ、興味深いずれがある。** にがみは表示上**最大の4**なのに、あなたは「**苦味も強すぎず**」と感じている。これはたぶん腕のほうの話で、**過抽出していない証拠**。苦味成分の後に出てくる渋み・えぐみ・収斂感が乗っていないので、**純粋な苦味だけがきれいに出ている**。同じ豆を雑に淹れれば、同じ「にがみ4」が「強すぎる」に化ける。

**「特徴をクリアに感じられている」の正体は、たぶん3つの合わせ技。** ①**淹れ方が安定した**（細口ケトルで注湯をコントロールできるようになり、偏流が減って均一に抽出できている）②**この豆が読みやすい**——レーダーチャートが偏っている＝**山と谷がはっきりした設計**なので、全軸3のUCCのような「無個性」型より格段に読み取りやすい ③**語彙が増えた**。フレーバーホイールの区画や抽出の軸を知ったことで、感じたものに名前が付くようになっている。**「腕が上がった」と「対象が読みやすい」と「言葉が増えた」は別々の要因で、今回は全部が同じ方向に効いた**。

なお賞味期限27.06.20から12ヶ月設定で逆算すると製造は**約3ヶ月前**。ハマヤ（約1ヶ月前）より古いが、**香りより苦味・コクで聴かせる設計の豆なので、鮮度落ちの影響が出にくい側**にある。香りが主役の豆ほどには時計を気にしなくてよい。

**次に試すこと。** ①**同じ豆をもう一度、条件を揃えて淹れる**——今回が「腕」なのか「豆」なのかは、次の一杯で分かる。レギュラーにするつもりなら基準の一杯を持っておく価値がある。②**細口ケトルの湯温対策（ケトルの予熱）を入れた一杯**と比べる。前回「薄くなった」件の検証がまだ済んでいない。③今後は袋を見たら**まず生豆生産国名の並び順を読む**。先頭が主役なので、飲む前に味の当たりがつく。
