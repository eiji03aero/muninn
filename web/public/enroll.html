この端末のパスキーを鍵スロットに登録する。以後この端末では Face ID だけでサイトが開く。

  1. パスワードを1回だけ入れる（本文の鍵をここで取り出す）
  2. パスキーを作り、その鍵で本文の鍵を包む
  3. 出てきた JSON を Claude に渡す（正本に載せると他の端末にも同期される）

ここで作られるのは「本文の鍵を包んだもの」で、包みを解けるのはこの端末のパスキーだけ。 JSON を公開しても本文は読めない。逆に、パスワードは今後も非常口として有効なままなので、 強くて長いものに変えておくほど安全になる（普段は打たないので長さで妥協する理由がもう無い）。
