◀この帯をなぞって めくる▶

依頼を書く

サイトからは書き込めない。ここで文面を作って伝票に溜め、あとでまとめて渡す。

本紙の読みかた
  1. 面は「めくる」。画面の下の帯を指でなぞると、一面 → 棚 → 索引 → 伝票と紙が動く。帯の名前を押せば直行もできる。
  2. 記事だけは「読む」。別刷りが下から上がってきたら、そこは縦に読む。めくる軸（下の帯・横）と読む軸（紙面・縦）は場所が違うので、ぶつからない。
  3. 一面の頭は今日の一問。答えを伏せた問いが出る。思い出してから［めくる］を押し、わかった／あやしいを打つ。
  4. リンクには「なぜ関連するか」が必ず書いてある。本文の欄外に、書いた本人の言葉のまま傍注として組んである。
