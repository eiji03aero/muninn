## 3案

| | 賭けている層 | 核となる一手 | 最大の賭け |
|---|---|---|---|
| **A 親指ひとつ** | **1操作の物理**（指を動かさない） | 原点を叩くと答えが出て、**原点が2つに割れる**（左＝あやしい／右＝わかった） | 方向の記憶が「1日数分」の利用頻度で育つか |
| **B 一本の欄** | **操作の構造**（モードを消す） | ゼロヒットが**「ここから先は muninn の外」**に変わり、そのまま Claude への依頼になる | 「欄に近いほど強い」という上向きの組版に体が馴染むか |
| **C 紙面をめくる** | **情報の重み付け**（組版で編集する） | 記事の欄外に**「傍註」としてリンク元が書いた理由**を組む | 横めくりが縦スクロールより読みやすいと言えるか（**実証は割れている**） |

**審査の結論**: 骨格は B、読む面の組版は C、想起の一手は A。
ただし**合成案の推奨ではない**——3つを混ぜると、各案が持っていた「法則がひとつしかないから予測できる」という最大の美点が壊れる。
**まず1案で骨格を通し**、そのうえで他案の一手を移植するか判断するのが正しい順序。迷うなら B から（実装コスト最小・引き返しが安い）。

## モックを動かす

モックは **muninn の実データ**で動く（ダミーテキストは一切使っていない）。データは派生物なのでコミットしていないため、初回だけ作り直す。

```sh
# 1. 平文の site.json を作る（MN_SITE_PASSWORD を設定していないこと）
cd web && npm run build:data && cd ..

# 2. モック用データ mn-data.js を作る
sh docs/web-uiux-experiment/mocks/make-data.sh

# 3. ローカルサーバで開く（file:// だと script src が読めない環境がある）
cd docs/web-uiux-experiment/mocks && python3 -m http.server 8899
#   → http://127.0.0.1:8899/mock-a.html  など
```

- モックは**素の HTML/CSS/JS**（フレームワークなし・外部リソースなし）。ビルド不要。
- 幅480px以下では画面いっぱい、それ以上では中央に **390×844 の端末フレーム**が出る。
- 各モックは起動時に「この案の核」のオーバーレイを1枚出す。

### 配布用に1ファイルへ畳む

```sh
node docs/web-uiux-experiment/mocks/build-publish.mjs
# → mocks/dist/*.html （データと画面写真を data URI で埋め込んだ自己完結HTML）
```

`shots/*.jpg` は `index.html` に埋め込まれる画面写真（実機サイズの切り出し）。

## この実験で得た、繰り返し効く事実

- **muninn 最大の未使用資産は「理由つき被リンク」**。`- [[x]] — なぜ関連するか` という規約のおかげで、
  Wikipedia の Page Previews より一段リッチな「**相手が書いた理由ごと覗ける**」が作れる。3案とも別々の形でこれを使った。
- **iOS Safari には Vibration API が無い**（2026年時点でも未実装）。触覚に依存する設計は PWA では成立しない。
- **force-directed のグラフビューは200ノート超で毛玉化**し、Obsidian/Roam 双方で「見て終わり」と評価が一致している。
  生き残っている代替は例外なく「物理シミュレーションをやめて、型付き・整列済み・テキストベースにする」方向に収束している。
- **「ズームはナビゲーションの答えではない」**（Pad++ → Prezi → Windows 8 が同じ結論に収束）。
  20年以上生き残った実用例は macOS Dock の拡大鏡＝**2D全体ではなく1次元の帯に fisheye を適用したもの**だけ。
- **無限キャンバス／横カラム積みはモバイル幅で原理的に死ぬ**（Miller columns・Matuschak の stacked pages・Heptabase・Scrintal）。
  muninn が読み専用なのはむしろ有利。
- **`recall`（想起の問い）は knowledge 59本すべてに入っている**（`web/DESIGN.md` §9 の「無い」という記述は古い）。
  本当の急所は「**59本すべてが復習期限を過ぎている**」ほうで、だから総量は絶対に画面に出さない。
