## 結論を先に

**半分本当で、半分は違います。**

- 「国際相場が2025年後半にピークをつけて下落」→ **本当**（ICEアラビカは2025年11月11日の $4.23/lb → 2026年6月9日に $2.3885/lb まで約43%下落）
- 「店頭価格は上がり続けている」→ **前年同月比では本当だが、水準は2026年3月にピークアウト済み**

つまり「相場↓ / 店頭↑」の同時進行ではなく、**店頭は約4か月遅れで同じ方向に動いている**、が実態に近いです。ただし直近7月に相場が再急騰しており、加えてUCCが2026年11月1日出荷分からの再値上げを既に発表しているので、この秋にまた上がります。

## 仮説（確からしい順）

### H1. 調達・在庫パイプラインのタイムラグ ★最有力

焙煎業者は生豆を数か月〜1年先渡しで買い付けるため、2025年11月のピーク価格で仕込んだ豆が、その後何か月も製品として流れ続ける。値上げ発表→納品にも構造的な遅れがある（UCCは2025年12月22日発表 → **2026年3月1日**納品分から10〜18%）。国際相場ピーク2025年11月 → 店頭ピーク2026年3月＝**ラグ約4か月**で、実際に観測された数字と整合。

**反証の方法**
- 財務省貿易統計／全日本コーヒー協会の**生豆輸入単価（円/kg、月次）**を店頭価格に重ねる。輸入単価が既に大きく下落しているのに店頭が横ばい以上なら、ラグでは説明できずH1は棄却。
- 相場ピークから6か月以上（＝2026年5月以降）経っても店頭が下がらなかったならH1は死ぬ。→ **実際には下がったので、現時点ではH1が生き残っている**。
- メーカー各社の在庫回転日数・原料手当て期間の開示（IR説明会資料）。手当て期間が1〜2か月と短ければラグ仮説は弱い。

### H2. 相場以外のコスト（人件費・物流・エネルギー・包材）＋円安 ★次点、H1と併存

小売価格に占める生豆コストは一部でしかなく、残りは国内コスト。そちらは相場と無関係にまだ上がり続けている。

**決定的な傍証**：UCCの値上げリリースの理由記述が変質しています。

- 2025年12月22日発表（3月実施、10〜18%）：「コーヒー生豆の国際価格が1970年代以来約半世紀ぶりの記録的高値」＋原材料・包材・物流・エネルギー＋「急激な円安」
- **2026年7月9日発表（11月1日出荷分、5〜10%）：「原材料や包装資材、エネルギー価格、そして人件費、物流費」「日本国内における物価上昇や昨今の国際情勢の変化、また継続的な円安の進行」——生豆相場への言及が消えている**

**反証の方法**
- 生豆コストの原価構成比を確定させる（未確認）。もし小売価格の7〜8割が生豆なら、H2の寄与は小さくH1一本になる。
- 日銀・企業物価指数の「飲料・食品」、企業向けサービス価格指数（道路貨物輸送）、毎月勤労統計の賃金指数を並べる。これらが横ばいならH2は棄却。
- **生豆のみを売る業者**（自家焙煎店の生豆通販）と**スーパーのレギュラーコーヒー**を比較。前者は国内加工コストの比重が低いので、H2が正しければ前者のほうが相場に忠実に下がっているはず。逆に両者が同じ動きならH2は弱い。

### H3. 価格改定の非対称性（上げは速く、下げは遅い）

メーカーは値上げはプレスリリースを出すが、値下げは基本的に発表しない。代わりに特売頻度・増量企画の復活という形で実効価格が下がるため、下落は緩慢かつ見えにくい。

**反証の方法**
- 小売物価統計（実売価格ベース、特売を含む）と、メーカー希望小売価格を並べる。**両者が乖離していればH3が働いている証拠**。ただし今回、小売物価統計側は既に −8.4% 下がっているので、「全く下がらない」という強い版のH3は既に棄却済み。
- 過去の相場サイクル（例：2011年高騰後の下落局面）で、店頭の下落ラグが上昇ラグより長かったかを検証。対称なら H3 は棄却。

### H4. 銘柄構成・調査対象の変化（構成効果）

観測しているのが「同じ商品の値段」ではなく「バスケットの平均」である以上、高価格帯へのシフトや小売物価統計の調査銘柄改定で段差が出る可能性。

**反証の方法**
- 特定SKU（例：UCCゴールドスペシャル 豆 200g）の実売価格を単独で追う。同じ形の山と下落が出ればH4は棄却。
- 総務省の小売物価統計「調査銘柄」改定履歴を確認し、2025年後半〜2026年に改定がなかったかを見る。改定がなければH4は棄却。
- 内容量変更（シュリンクフレーション）については、小売物価統計もCPIも100g換算なので原理的に捕捉済み。ここは説明力が低い。

### H5. アラビカ先物 ≠ 日本が買っている豆

報道される「国際相場」はICEアラビカ期近。日本の輸入はブラジル・ベトナム・コロンビアで約4分の3を占め、実際の調達価格は先物＋ディファレンシャル（現物プレミアム）。先物が下がってもディファレンシャルが高止まりすれば、実勢の仕入れ値は下がらない。

**反証の方法**
- ICOのグループ別指標（Colombian Milds / Other Milds / Brazilian Naturals / Robustas）を個別に見る。全グループがI-CIPと同率で下落していればH5は棄却。
- 財務省貿易統計の**国別**輸入単価（円/kg）。ブラジル産・ベトナム産の単価が先物と同じテンポで下がっていればH5は棄却。

### H6. 米国の対ブラジル関税による貿易フロー転換 ★最も弱い、むしろ逆向き

2025年の対ブラジル50%関税は最高裁で無効化され、2026年7月にはインスタントコーヒーがSection 301の25%関税から除外されました。仮に米国向けが割高でも、それは**ブラジル豆が米国以外（＝日本を含む）に流れる**ことを意味し、日本の調達価格には**下押し**に働くはず。日本の店頭高を説明する向きが逆なので最下位。

**反証の方法**
- 日本の対ブラジル輸入単価が、関税賦課期間中に相対的に下がったかを見る。下がっていれば「米国要因は日本には値下げ圧力」が確定し、この仮説は値上げ説明としては完全に棄却。

## なぜこの順番か

順位は **①観測された数字を定量的にどれだけ説明できるか → ②既に直接証拠があるか → ③メカニズムが具体的で反証可能か** の順で付けました。

- **H1が1位**なのは、「国際ピーク2025年11月／店頭ピーク2026年3月」という4か月ラグと、「発表12月22日／実施3月1日」という制度的ラグが独立に同じ長さを示していて、時系列の形そのものが仮説の予言と一致しているから。しかも「その後店頭は下がるはず」という予測が既に実現しています（358→328円）。
- **H2が2位**なのは、値上げリリースの理由文が「生豆相場」から「人件費・国内物価」へ書き換わったという**一次情報の直接証拠**があるから。ただし寄与度を数値化できていない（原価構成比が未確認）ので1位にはできません。H1とH2は排他ではなく、H1が2025年後半〜2026年3月を、H2が2026年11月以降を説明する、という時期の住み分けが最も自然だと考えます。
- **H3以下**は、「効いていても不思議ではないが、今回の +23〜26% という大きさを主因として説明するには足りない」ため。特にH3は、実売価格が既に8%下がっている時点で強い版が反証されています。
- **H6が最下位**は、効果の符号が説明したい現象と逆だから。
