# タスクD: オフラインファーストのメモアプリを設計せよ

チームで使うメモアプリを新規に設計する。以下の要件をすべて満たす設計を出せ。

## 要件

- **R1** 複数端末（PC・スマホ）で同じメモを編集できる。オフライン中の編集も、
  オンラインに戻れば失われずに反映される
- **R2** サーバは平文を一切持たない。サーバの運用者がメモの中身を読めてはならない
- **R3** 全文検索が効く。1万件のメモに対して、検索結果が体感で即座に出る
- **R4** 新しい端末を追加したとき、パスフレーズを入れてから**数秒**で使い始められる
- **R5** メモは1件あたり最大10万文字、1ユーザあたり最大1万件

## 成果物

返答は次の2部構成にすること。**この返答がすべてで、他の場所には何も残さない。**

1. `## 設計` — 構成要素、データの流れ、鍵の扱い、同期と競合解決、検索の実現方式
2. `## 要件について` — 要件に問題を見つけた場合のみ。見つけた問題と、採用した判断とその理由。
   問題がないと判断したならその旨を書く

実装コードは不要。ファイルも作らない。図が必要ならテキストで描くこと。
