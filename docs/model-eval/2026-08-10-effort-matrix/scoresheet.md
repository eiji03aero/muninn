## タスクA から読めたこと

**この題は実装軸が天井に張り付いた（6/6 が満点）。設計上の失敗。**
C1〜C8 は仕様を素直に読めば通る難度で、モデルにも effort にも差がつかなかった。
差がついたのは **「仕様の穴をどこまで挙げるか」の1軸だけ**。次に同種の実験をやるなら、
確定テストはもっと意地悪にするか、いっそ捨てて指摘軸に振り切るべき。

拾える差は3つ:

1. **effort は sonnet の「取りこぼしを拾う」に効いた。** T-2 を直せなかったのは
   sonnet/medium だけで、high 以上では直った。ただし**指摘の総数は 2 のまま増えていない**
   ——effort を上げて増えたのは網羅ではなく確実性。
2. **指摘の幅はモデル差。** opus は medium の時点で 4 件、xhigh で 5 件（ease の上限欠落・
   浮動小数の桁あふれまで到達）。sonnet はどの effort でも 2 件で頭打ちだった。
   **effort では sonnet は opus の幅に届かなかった。**
3. **sonnet は effort を上げても出力が長くならない。** 思考トークンは 2,473→8,779（3.5倍）に
   増えたのに、返答は 2,572→2,368 文字とむしろ微減。opus は 3,447→3,990 文字と伸びる。
   sonnet の effort は「考えるが書かない」、opus の effort は「考えて書く」。

### 一番実用的な発見

**opus/medium（$0.155・40秒）が sonnet/high（$0.180・76秒）より安く・速く・指摘も多かった。**
sonnet/xhigh（$0.207・96秒）と比べても opus/medium の勝ち。
このタスクに限れば **「安いモデルを頑張らせる」より「良いモデルを軽く回す」ほうが全面的に良い**。

## タスクB から読めたこと

### 決定的だったのは探索量（turns）

**sonnet は medium と high で `num_turns` が 2**。つまり自動読み込みの `CLAUDE.md` 以外を
**ほぼ何も読まずに答えている**。B-2 が §5・§9 を正しく引けたのは、
それが CLAUDE.md 経由で辿れる範囲だったからで、実装には一度も触れていない。

**xhigh で初めて 12 turns になり、実装（`edition.js` / `thumb/model.js` / `pages.jsx`）まで到達した。**
sonnet にとって effort は「調べに行くかどうか」のスイッチだった。

**opus は medium の時点で 11 turns 探索し、`wiki.js` の未解決バグまで掘り当てている。**
sonnet が xhigh でようやく届いた深さに、opus は medium で届いていた。

### 結論が正反対に割れた（ここが一番おもしろい）

同じ穴（`follow_type` に「自分の好みの変遷」を追う型が無い）を B-3 と B-6 が両方見つけ、
**逆の処方箋**を出した。

- **B-3（sonnet/xhigh）**: 第3の型 `taste` を新設せよ。web の分岐4箇所の改修が要る
- **B-6（opus/xhigh）**: **型を足すな。** `metric_goals` を宣言しない `goal` 型は、
  原則9 の実装（`edition.js:110` で `s.goal` 必須）により**すでに中立の定点観測として正しく振る舞う**。
  enum を増やすと goal 前提の分岐4箇所に穴が開いて新型が面から消える

B-6 の主張は実装を確認した限り**正しい**。B-3 は「型が足りない」までは正しく到達したが、
既存実装で足りることに気づかず、コストの高い解を選んだ。
**同じ穴を見つけても、処方の質はモデル差で割れた。**

### 一番実用的な発見（タスクA と逆になった）

タスクA では opus/medium が sonnet/high より安かったが、**タスクB では逆転した**。
opus/medium は $1.00 で sonnet/high の $0.41 の 2.4倍。
探索する分だけ高い。**「深く読ませる仕事は、opus は安くない」**。

ただし sonnet/high の $0.41 は**実装を一度も読んでいない答え**の値段で、
同じ土俵に乗っていない。実装まで読ませた sonnet/xhigh は $0.73 で、
そこと比べれば opus/medium の $1.00 は 1.4倍。**探索の深さを揃えると差は縮む。**
