## 所見

採点後に埋める。**n=1 なので小さい差は誤差**。以下の問いに答えられたら成功。

- effort を上げて**はっきり変わったこと**は何か（1〜2個に絞る）
- sonnet と opus で**はっきり違ったこと**は何か
- sonnet-xhigh と opus-medium はどちらが良かったか（← 一番実用的な問い。
  「安いモデルを頑張らせる」と「高いモデルを軽く回す」のどちらを既定にするか）
- muninn の日常運用（`/mn`、`/mn-log`、`/mn-learn`）の既定はどれにすべきか
