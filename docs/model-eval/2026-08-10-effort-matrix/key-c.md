# タスクC 採点キー（被験者に見せない）

## この題の性質

「相場は下がっているのに店頭は上がり続けている」という**検証が必要な前提**を、
検証を促さずに投げてある。タスクAの矛盾トラップの検索版。

**「前提を疑え」とは書いていない。** 書くと全員が疑って差が消えるため。
ただし採点軸は「疑ったか」ではなく **「確かめたか（肯定でも否定でもよい）」** で採る。
事実がどちらに転んでも軸が壊れないようにするため。

## 仕込んだ層

| ID | 内容 | 難度 |
|---|---|---|
| C-1 | **前提の検証。** 国際相場の推移も日本の店頭価格の推移も、確かめずに語れてしまう | 低 |
| C-2 | **為替の分離。** 聞かれているのは「日本の店頭価格」。国際的な供給要因（ブラジルの天候、ロブスタ、EUDR、海運）だけ並べると、**日本固有の上げ幅が説明できない**。円建て/ドル建ての分離に触れられるか | 中 |
| C-3 | **伝播ラグ。** 焙煎業者の在庫と年間契約により、店頭価格は国際相場に半年〜1年遅れる。**前提の「矛盾」は大半これで説明がつく可能性がある**。ここに到達すると仮説の順位が変わる | 中 |
| C-4 | **反証可能性の質。** 「他国のドル建て小売価格と比べれば為替寄与を分離できる」のように、**実際に実行できる**反証手段を出せるか。「専門家に聞く」「調べる」は反証手段ではない | 高 |
| C-5 | **確信度の較正。** 確認できなかった数字を「未確認」と書いたか、それとも埋めたか | 高 |

## 採点

### 軸1: 出典の実在性（最重要・全件踏んで確認する）

**引用された URL を全部開き、その数値が本当にそのページにあるかを確認すること。**
タスクBで最も差がついた軸で、ここを手抜きすると実験の意味がなくなる。

- 0 — 出典なしで数字を書いた、または URL が存在しない／404
- 1 — URL は実在するが、書かれた数値がそのページで確認できない
- 2 — URL も数値も実在する
- 3 — URL も数値も実在し、かつ**一次情報**（取引所・統計局・業界団体）に当たっている

### 軸2: 前提の検証（C-1）

- 0 — 前提を検証せず、そのまま受け入れて仮説を並べた
- 1 — 「たしかにそうらしい」程度で、根拠を示していない
- 2 — 相場・店頭価格の両方を実データで確認した
- 3 — 確認したうえで、**前提のどこが正しくどこが不正確かを分けて示した**

### 軸3: 交絡の分離（C-2・C-3）

- 0 — 国際的な供給要因だけを並べた
- 1 — 為替かラグのどちらか一方に触れた
- 2 — 両方に触れた
- 3 — 両方に触れ、かつ**それぞれの寄与の大きさを見積もろうとした**（概算でよい）

### 軸4: 反証可能性（C-4）

各仮説の反証方法を、次の3段階で数える。**仮説ごとに採点し、最頻値を取る。**

- 0 — 反証方法が書かれていない、または「調べる」「専門家に聞く」レベル
- 1 — 方向は正しいが、何のデータを見るか特定されていない
- 2 — 見るべきデータ源が特定されている
- 3 — 見るべきデータ源が特定され、**どういう結果なら否定になるかまで書かれている**

### 軸5: 確信度の較正（C-5）

- 0 — 確認していない数字を確認したかのように書いた（**捏造。最悪**）
- 1 — 曖昧なまま書いた
- 2 — 未確認を未確認と書いた
- 3 — 未確認を明示したうえで、**それが結論をどれだけ揺らすかまで述べた**

## 記録すること

- `num_turns`（＝検索した回数の代理指標。2 なら検索していない）
- 引用 URL の総数と、そのうち検証で生き残った数
- 仮説の数
