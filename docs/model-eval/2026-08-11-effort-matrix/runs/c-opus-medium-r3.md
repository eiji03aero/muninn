## 結論を先に

「相場は下がっているのに店頭は上がり続けている」は**半分本当で、半分はもう古い**です。

- 国際相場：**2025年10月23日に437.95セント/lbでピーク** → 2026年6月9日に242.70セントまで下落 → 2026年8月14日時点で316.55セント（30日で-5.4%）（[TradingEconomics](https://tradingeconomics.com/commodity/coffee/news/547517)）。ピークからは約▲28%ですが、6月の底からは戻しています。
- 日本の店頭：CPI「コーヒー豆」は**2026年3月の261.8がピーク**で、直近238.5・前年比+23.3%（前年比のピークは2025年9月の+64.1%）（[アイ・エヌ情報センター（総務省CPI集計）](https://www.indb.co.jp/insight/economydata_2607_cpizennkoku/) / 原統計は[総務省 2026年6月分](https://www.soumu.go.jp/menu_news/s-news/01toukei08_01000347.html)）。※238.5が6月分か7月分かは情報源で記述が割れており**未確認**です。
- 小売物価統計のレギュラーコーヒー粉100gも同じ形：2025年1月 ¥227 → 2025年12月 ¥340 → **2026年3月 ¥357（ピーク）** → 4月 ¥349 → 5月 ¥337 → 6月 ¥328（[物価高騰ランキングW3G／小売物価統計調査](https://price.w3g.jp/coffee-grounds)）。

つまり実態は「**相場ピークの約5ヶ月後に店頭がピークアウトし、店頭も既に下がり始めている。ただし前年比では+23%なので体感は上がりっぱなし**」です。感覚が「上がり続けている」なのは、水準ではなく1年前との比較で感じているためだと思われます。

## 仮説（確からしい順）

順序の基準は「① 観測されたタイミングと大きさをどれだけ直接説明するか ② 一次データで裏が取れているか」の2点です。

### 1. 価格転嫁のタイムラグ（最有力）
在庫・先渡契約・値上げ発表→実施の商流ラグ。実際の日付が綺麗に並びます：相場ピーク2025年10月 → **UCC値上げ発表2025年12月22日／実施2026年3月1日出荷分**（[UCC公式](https://www.ucc.co.jp/company/news/2025/rel251222.html)）、キーコーヒーも2025年12月発表・2026年3月納品分から → CPIピーク2026年3月。ラグは約4〜5ヶ月。

**反証方法**：CPI「コーヒー豆」水準が2026年後半以降も上昇に転じ続けたら、ラグでは説明しきれない。また相場（円建て換算）とCPIの相互相関を取り、最適ラグが月ごとに不安定・符号が反転するなら棄却。

### 2. 円建てでは相場ほど下がっていない（円安が緩衝材）
ドル円は2026年8月中旬で約159円（[外為どっとコム 2026/8/12](https://www.gaitame.com/media/entry/2026/08/12/074703)）。ドル建て▲28%でも、円安が同時進行していれば円建て投入コストの下落幅は小さくなります。※2025年8月時点のドル円との厳密な比較は**未確認**。

**反証方法**：財務省貿易統計のコーヒー生豆CIF単価（円/kg）を月次で見る。これがドル建て相場とほぼ同率で下がっているなら、円安は効いておらずこの仮説は棄却。

### 3. 豆以外のコストが下がらない（人件費・物流・包装・エネルギー）
小売価格に占める生豆コストは一部で、他は下方硬直的。実際、値上げ理由に包装用合成樹脂コストの上昇が挙げられています（[W3G](https://price.w3g.jp/coffee-grounds)）。

**反証方法**：日銀・企業物価指数の「包装資材」「道路貨物輸送」サブ指数を確認。これらが横ばい〜下落なのに店頭だけ高止まりなら棄却。メーカーの値上げリリースが挙げる理由の内訳も手がかり。

### 4. 価格の下方硬直性（メニューコスト・値ごろ感価格帯）
一度上げた棚価格は、原価が下がっても据え置かれやすい。1,280円などの価格帯に張り付く。

**反証方法**：棚価格ではなく**POS実売単価**（日経POS、インテージSRI+）と特売頻度・値引き率を見る。棚価格据置でも実売単価が下がっていれば「値下げは特売で行われている」＝この仮説を支持。実売単価も横ばいなら、硬直性より仮説2・3の方が効いている。

### 5. マージンの拡大（いわゆる便乗値上げ）
相場下落分をメーカー／小売が抱えている可能性。ただしこれを1〜4より上に置く根拠は現時点でありません。

**反証方法**：UCCホールディングス・キーコーヒーの決算短信で**売上総利益率**を四半期で追う。相場下落局面（2026年上期）に粗利率が明確に改善していれば支持、横ばい以下なら棄却。

### 6. 実質値上げ（内容量変更・銘柄構成のシフト）
200g→180gのような容量変更や、安価銘柄の終売による構成変化。

**反証方法**：CPIは品質・容量調整済みなので、CPIと「単純平均の店頭価格」の乖離を見る。乖離が小さければ棄却。同一JANコードで100g単価を追うのが最も直接的。

### 7. 先物とスペシャルティ実勢の乖離（ディファレンシャル高止まり）
ご自身が買っているのがスペシャルティ／シングルオリジンなら、ニューヨークC相場が下がってもプレミアム（ディファレンシャル）が高止まりして体感が動かない可能性。**個人の実感と統計がズレる場合、これが本命になり得ます。**

**反証方法**：輸入商社（石光商事、ワタル等）の産地別オファー価格や、購入している焙煎店の生豆仕入価格を直接聞く。C相場と同率で下がっていれば棄却。

### 8. 米国の対ブラジル関税（最も可能性が低い）
2025年の米国関税は米国の店頭に効くもので、日本の小売価格への直接経路は弱い。世界需給を通じた間接効果に留まる。

**反証方法**：関税発動・撤回のイベント日前後で、日本の生豆CIF円建て単価にステップ状の変化があるかを見る。なければ棄却。
