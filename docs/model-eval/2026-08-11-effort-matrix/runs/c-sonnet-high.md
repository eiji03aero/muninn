海外相場・為替・日本の店頭価格それぞれの実データを確認しました。結論から言うと、**「相場は下がっているのに店頭は上がり続けている」という前提自体がやや不正確**です。実際には日本のコーヒー豆の小売価格（CPI）は2026年3月をピークにすでに下がり始めています。ただし「肌感覚として値上がりした」のは事実で、そこにはいくつかの構造要因が重なっています。

## 1. まず前提を検証する

**国際相場（ドル建て）**
- アラビカ種（ICE先物）は2025年2月に431¢/lb前後で史上最高値をつけた後、乱高下しながら下落基調 → 2025年7月に272¢まで下落 → 2025年8月に391¢まで反発 → 2026年6月には238.85¢まで下落（2026年の安値）→ 2026年7月上旬には357¢まで急反発（史上最大級の週間上昇率）（[TradingEconomics/Barchart経由の要約](https://tradingeconomics.com/commodity/coffee/news/495120), [Barchart](https://www.barchart.com/story/news/34701320/why-is-coffee-back-in-bullish-mode)）
  → **「下がり続けている」というより「乱高下しながらピークからは離れている」が正確**。特に2026年7月は急反発しており、直近だけ見れば「相場は上がっている」とも言える局面です。
- ロブスタ種（ロンドン先物）は2025年ピーク時の約5,200USD/tから、2025年6月に4,133USD/t（10ヶ月ぶり安値）、2026年5月時点で3,345USD/t（2026年7月限）まで、こちらはアラビカよりも明確な下落トレンド（[Bloomberg](https://www.bloomberg.com/jp/news/articles/2025-06-16/SXX6Y5T1UM0W00), [vietnam.vn](https://www.vietnam.vn/ja/gia-ca-phe-hom-nay-20-5-2026-gia-the-gioi-phuc-hoi-gia-trong-nuoc-tiep-tuc-lao-doc)）

**日本の店頭価格（小売物価統計調査・CPI、総務省）**
- コーヒー豆のCPI（2020年=100）は2026年3月に261.8でピーク → 5月247.2 → 7月238.5（前年同月比+23.3%）と、**直近4ヶ月連続で低下中**（[gdfreak（総務省CPI集計）](https://jp.gdfreak.com/public/detail/jp010050006070101229/1), [アイ・エヌ情報センター 2026年7月データ](https://www.indb.co.jp/insight/economydata_2607_cpizennkoku/)）
- 参考：2026年2月の47都市平均・小売物価は100gあたり351円（[アイ・エヌ情報センター等の要約](https://www.pricey.jp/web/articles/2582)）
- 2026年3月の前年同月比+54.0%という数字もSNS上で流通していますが、これは公式統計サイトではなくX（旧Twitter）の集計botの投稿であり**未確認**として扱います（[該当ポスト](https://x.com/indbgraphreport/status/2047536900928573667)）。

→ つまり「ここ1年で上がった」という体感は正しい（前年同月比+23%はまだ相当な水準）が、「今も上がり続けている」は8月時点では事実と異なり、**すでにピークアウトして頭打ち〜緩やかな低下局面**に入っています。

## 2. 仮説（確からしい順）

### 仮説1：体感と統計のタイムラグ・認知のズレ（最有力）
実際には店頭価格は2026年3月をピークに下がり始めている。ユーザーが「上がり続けている」と感じるのは、①値上げの"発表"が2025年末〜2026年前半に集中して報道され続けたため印象が強く残っている、②前年同月比では依然+20%超なので絶対水準としては「高いまま」に見える、という認知的な理由が大きい可能性。

**なぜ最有力か**：これは推論ではなく統計データ（総務省CPI）が直接示している事実。

**反証方法**：総務省の小売物価統計調査・CPI（e-Statまたは同等の集計サイト）で直近3〜6ヶ月のコーヒー豆指数を確認する。もし直近月も指数が上昇し続けていれば、この仮説は否定される。逆にユーザーの購入している具体的な商品・店舗の価格が全国平均と乖離して上がり続けているなら、店舗・銘柄固有の要因を疑う必要がある。

### 仮説2：価格転嫁のタイムラグ（仕入れ契約・在庫サイクル）
生豆は商社が数ヶ月〜半年程度前に買い付け、在庫は次の収穫まで約1年かけて消費される。そのためメーカーの値上げは「今の相場」ではなく「数ヶ月〜1年前の仕入れコスト」を反映して実施される。実際、UCCは2025年12月・2026年3月・2026年7月発表（11月実施）と**複数回にわたり段階的に値上げを発表**しており、2025年2月の史上最高値がタイムラグを伴って店頭に反映され続けている構図と整合的（[UCC 2025年12月発表](https://www.ucc.co.jp/company/news/2025/rel251222.html), [UCC 2026年7月発表](https://www.ucc.co.jp/company/news/2026/rel260709.html)）。

**なぜ2番目か**：サプライチェーンの構造自体は業界の一般知識として確認できるが、「今回の値上げが具体的に何ヶ月前の相場を根拠にしているか」まではプレスリリースから直接特定できていない（推論を含む）。

**反証方法**：各メーカーの値上げ発表文で言及されている契約・仕入れ時期を確認し、直近1〜2ヶ月以内の相場を根拠にしているなら「ラグ」では説明できない。また商社の実際の買い付けリードタイム（何ヶ月先まで契約を確定しているか）を一次情報（商社IR・業界団体資料）で確認する。

### 仮説3：円安による為替相殺
ドル建て相場が下がっても、同時に円が対ドルで安いままなら円建て輸入コストはそこまで下がらない。2025年12月時点で150円台、2026年の予測も146〜155円台のレンジで大きくは戻っていない（[三井住友DSアセットマネジメント](https://www.smd-am.co.jp/market/ichikawa/2025/12/irepo251226/), [野村證券](https://www.nomura.co.jp/wealthstyle/article/0676/)）。UCC自身も2026年11月からの値上げ理由に**「円安進行」を明記**している（[UCC 2026年7月発表](https://www.ucc.co.jp/company/news/2026/rel260709.html)）。

**なぜ3番目か**：為替の事実自体は確実だが、これだけでは「下落を鈍らせる」要因の説明にとどまり、「上がり続ける」ことの主因とまでは言い切れない（企業も複合理由の一つとして挙げているに過ぎない）。

**反証方法**：財務省貿易統計・全日本コーヒー協会の輸入統計から、円建ての生豆輸入単価（CIF価格×為替）の推移を確認する。ドル建て国際相場の下落率と比べて円建て輸入価格の下落率が明らかに小さい、または上昇していれば仮説を支持。同程度に下落していれば為替は主因ではない。（今回この一次データそのものは検索でリンクは見つかったが具体的な数値は取得できなかったため、**この裏付け数値自体は未確認**：[財務省貿易統計コーヒー生豆](https://www.toukei-is.com/?p=0150101&ie=0)）

### 仮説4：品種構成のズレ（アラビカとロブスタで動きが違う）
アラビカは乱高下しつつ高値圏、ロブスタはより明確に下落基調と、銘柄によって値動きが異なる。「国際相場が下がっている」という話がどちらの銘柄を指しているか、また対象商品（レギュラーコーヒー/インスタント）がどちらを主原料にしているかによって、体感と実態がズレる可能性。

**なぜ4番目か**：値動きの違い自体はデータで確認できるが、それが実際に日本の各商品の原価にどう反映されているかまでは検索だけでは特定できず、確度は中程度にとどまる。

**反証方法**：各メーカーの原料調達構成（アラビカ比率/ロブスタ比率）をIR資料等で確認し、値上げのタイミングがどちらの相場と相関しているか照合する。

### 仮説5：便乗値上げ・複合コスト要因（コーヒー相場以外の理由）
値上げ発表文には「包装資材」「エネルギー」「人件費・物流費」など、コーヒー豆相場以外の理由も並記されており、値上げ幅が原料費上昇分だけでは説明できない可能性。

**なぜ最も確度が低いか**：これを裏付ける具体的な数字（原価上昇分と値上げ幅の差、値上げ後の粗利率変化など）を見つけられなかったため。複合理由を挙げること自体は一般的な値上げ発表の作法であり、それだけでは便乗値上げの証拠にはならない。

**反証方法**：対象メーカーの有価証券報告書等で、原材料費率・売上総利益率が値上げ前後でどう推移したかを確認する。値上げ後に粗利率が明確に改善していれば支持材料、横ばい・悪化していれば否定材料。
