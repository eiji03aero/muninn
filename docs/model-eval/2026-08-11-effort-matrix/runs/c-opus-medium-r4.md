## まず事実確認：前提は「半分正しい」

### 国際相場（ICEアラビカ先物）

| 時点 | 価格 | 備考 |
|---|---|---|
| 2025年2月 | **$4.41/lb** | 史上最高値 |
| 2025年11月11日 | **$4.23/lb** | 2025年後半のピーク |
| 2026年6月9日 | **$2.3885/lb** | 19か月ぶり安値（ブラジル豊作見通し） |
| 2026年7月6-7日 | **$3.52〜3.57/lb** | 週間上昇率が2000年以来最大の急反発 |
| 2026年8月14日 | **$3.12/lb** | 前月比 −4.51%、前年比 **−8.68%** |

出典: [Trading Economics](https://tradingeconomics.com/commodity/coffee)、[Perfect Daily Grind 6月](https://perfectdailygrind.com/2026/06/coffee-news-recap-5-june-2026/)、[cocoaintel（7月の急騰）](https://www.cocoaintel.com/frost-concerns-trigger-sharp-rally-as-supply-fundamentals-remain-in-focus-6-july-2/)

→ 「2025年後半にピークをつけて下がった」は**方向としては正しい**。ただし単調下落ではなく、2026年6月に底を打って7月に短期間で1.5倍近く戻した**V字**です。「もう下がっている」と言い切れるほど落ち着いてはいません。

### 日本の店頭（CPI「コーヒー豆」前年同月比）

- 2026年3月: **+54.0%** ([総務省CPI 2026年3月分](https://www.soumu.go.jp/menu_news/s-news/01toukei08_01000341.html)、品目別の数値は[この集計](https://x.com/indbgraphreport/status/2047536900928573667)経由)
- 2026年6月: **+23.3%** ([money-pro による6月分CPI集計](https://money-pro.net/news/20260724/))

→ ここが重要です。**「上がり続けている」のではなく、「非常に高い水準に張り付いたまま、上昇率が急減速している」**のが実態。第一生命経済研も、コーヒー・ココアは「前年の急上昇の裏が出たことでプラス幅を縮小させている」としています（[レポート](https://www.dlri.co.jp/report/macro/634631.html)）。

ただし値上げ発表自体はまだ続いています（ネスレ 8/1 ゴールドブレンド約14%、タリーズ 8/5、無印良品 9/4、キリン 10/1、サントリー 11/1 など。[一覧](https://koyo-coffee.com/coffee-price-increase-2026/)）。

**未確認**: CPI「コーヒー豆」の**指数水準そのもの**（前月比）は確認できていません。前年比の減速＝水準の下落ではないので、ここは断定できません。

### 為替を噛ませると絵が変わる

| 月 | ドル円（月中平均） |
|---|---|
| 2025年8月 | 147.67 |
| 2025年11月 | 155.00 |
| 2026年7月 | **162.61** |

出典: [世界経済のネタ帳](https://ecodb.net/exchange/usd_jpy.html)、直近は8/13時点で159円台半ば（[OANDA](https://www.oanda.jp/lab-education/market_news/2026_08_13_usdjpy/)）

以下は**私の概算（一次ソースなし）**です:

- 2025年11月ピーク: $4.23 × 155.00 ≒ **¥1,446/kg**
- 2025年8月: 約$3.42 × 147.67 ≒ **¥1,113/kg**
- 2026年8月: $3.12 × 159.5 ≒ **¥1,097/kg**

→ **円建て生豆は、前年比ほぼ横ばい**（ドル建て −8.7%が円安でほぼ相殺）。ピーク比では −24%。

## 仮説（確からしい順）

順位の基準は「①時系列の整合性が実データで確認できるか → ②定量的な説明力の大きさ → ③自分で数字を確認できているか」の順です。

### H1. 価格転嫁ラグ ＋ 年1回の建値改定（最有力）

日本のロースターは相場に日次で追随せず、年数回まとめて建値を改定します。実際のタイミング:

- UCC: **2025年12月22日発表 → 2026年3月1日出荷分**から、店頭10〜18%
- キーコーヒー: **2025年12月12日発表 → 2026年3月1日納品分**から、店頭10〜30%

出典: [zatsulabo（UCC）](https://www.zatsulabo.com/ucc-price-increase-2026/)、[pricey](https://www.pricey.jp/web/articles/4591)

つまり**相場が$4.2でピークをつけていた2025年12月に決めた値段が、2026年3月に店頭に出てきた**。さらに焙煎業者の在庫回転（生豆調達から店頭まで数か月〜1年）が重なる。1位にした理由は、**発表日と相場ピークが実データでピタリ一致している**唯一の仮説だからです。CPIが3月+54% → 6月+23%と減速しているのも、この「3月の一発」が前年比に効いた後、追加の押し上げが止まったこととして整合します。

**反証方法**: 2026年秋〜2027年春の建値改定で、据え置きまたは値下げが**出なければ**この仮説は弱い（ラグ説なら、2026年6月の$2.39を織り込んだ改定がどこかで出るはず）。また、UCC・キーコーヒーの決算説明資料で原価率・棚卸資産評価が相場に何か月遅れで動いているかを見る。ラグが1年未満のはずなのに2年遅れているなら別要因。

### H2. 円安が国際相場の下落を打ち消している

ドル建て −8.68% に対し、ドル円は147.67 → 162.61（+10%）。**円建てでは実質ゼロ**。上の概算のとおりです。2位の理由は、数字が全部一次ソースで取れて説明力も大きい一方、「ピーク比 −24%」の部分は円安でも消しきれないため、単独では divergence 全部を説明できないから。

**反証方法**: 財務省貿易統計のコーヒー生豆CIF円建てkg単価（e-Stat 概況品別）を2025年8月〜2026年6月で並べる。**円建て単価が実際に下がっているのに店頭が上がっていれば、この仮説では足りない**ことになる。私はこの実数を確認できていません（**未確認**）。全日本コーヒー協会の[月間レポート](https://coffee.ajca.or.jp/data/report/)も同じ目的に使えます。

### H3. 先物価格 ≠ 実際の仕入れ値（現物の逼迫が続いている）

ICE認証在庫は236,430袋と歴史的低水準([Trading Economics](https://tradingeconomics.com/commodity/coffee))、ブラジルの在庫も2年ぶり低水準([Rockmart Week 32レポート](https://rockmartholdings.com/brazil-coffee-market-report-week-32-2026-harvest-drags-stocks-crumble-to-a-two-year-low/))。先物が下がっても、**ディファレンシャル（産地・等級ごとの上乗せ）**が拡大していれば、実際の生豆調達コストは下がらない。スペシャルティ系はこれが特に効きます。3位の理由は、メカニズムとして極めてもっともらしい一方、ディファレンシャルの実数値を私は確認できていないため（**未確認**）。

**反証方法**: ICE認証在庫の回復と同時にディファレンシャルも縮小しているのに店頭が上がるなら反証。国内生豆問屋（例: [コーヒー流通センター](https://www.coffee-rc.jp/news/detail/5)のような価格改定告知）の実売価格表を先物と並べ、乖離が拡大しているか確認する。

### H4. 豆以外のコスト（人件費・包装・物流・エネルギー）

第一生命経済研も、値上げ要因として原材料費だけでなく輸送費・容器包装・人件費・光熱費を挙げています（[同レポート](https://www.dlri.co.jp/report/macro/634631.html)）。焙煎豆の小売価格に占める生豆コストは全部ではない。4位の理由は、**確実に存在するが、説明できる幅が小さい**から。食料品（生鮮除く）全体が+3.1%なのに対しコーヒー豆は+23.3%で、この差はコスト全般では説明できません。

**反証方法**: コーヒー豆CPIと「加工食品全体CPI」の差分を取る。差分がほぼゼロならこの仮説が主因。実際は差が大きいので、これは**主因ではない**とほぼ言える。

### H5. 非対称転嫁（rockets and feathers：上げは速く下げは遅い）

値上げは即座に転嫁し、値下げは遅らせて利益率を回復させる、という一般的な小売行動。5位の理由は、理論としては確立しているが、H1（ラグ）と観測上ほぼ区別がつかず、今回のデータだけでは切り分けられないから。

**反証方法**: 前サイクル（2011年のピーク → 2013年の急落）で日本のCPIコーヒー豆がどれだけ、どのくらいの遅れで下がったかを見る。素直に下がっていれば非対称性は弱く、H1で十分。下がっていなければH5が効いている。

### H6. 実質値上げ・商品構成の変化

内容量削減、ブレンド比率の変更（安価なロブスタ増量）、店頭のスペシャルティ寄せ。CPIは品質調整するので指数には出にくいが、**買い手の体感には直撃**します。6位の理由は、確実に起きているが、CPI+23%という指標側の動きは説明しないから。

**反証方法**: 自分が買っている**同一SKU**の g単価を時系列で並べる。内容量が変わっていなければこの仮説は効いていない。

### H7. 体感バイアス／購入チャネル固有の事情

自家焙煎店や小規模ロースターは小ロット調達で在庫回転が遅く、大手より転嫁が遅れて来る。また記憶は上げ幅を過大評価しがち。最下位なのは、CPI+54%/+23%という客観データが「気のせい」を否定しているから。ただしチャネル差は残ります。

**反証方法**: 自分のレシートの g単価推移とCPIコーヒー豆指数を重ねる。自分の方が大幅に上振れていれば、店固有の要因（H7）が上乗せされている。

## いま一番効く検証3つ

1. **財務省貿易統計の生豆CIF円建てkg単価**を2025年8月〜直近で並べる → H1とH2をきれいに切り分けられる（これが下がっていて店頭が上がっていれば、原因はロースター側にある）
2. **CPI「コーヒー豆」の指数水準の前月比** → 「上がり続けている」のか「高原に張り付いている」のかが確定する
3. **2026年秋〜2027年春の建値改定の方向** → 据え置き/値下げが出ればH1、出なければH3かH5

私の見立ては、**H1（ラグ）+ H2（円安）で divergence の8割は説明でき、H3が残りを埋める**、というものです。円建て生豆が前年比横ばいである以上、「店頭だけが不自然に上がっている」わけではなく、**2025年末の高値をいま払っている**というのが実態に近い。
