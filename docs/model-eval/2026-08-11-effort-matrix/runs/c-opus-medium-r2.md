## 結論から

「相場は下がっているのに店頭は上がり続けている」は、**2026年3月頃までは事実だった。ただし今はもう成立していない**（日本の店頭も4月以降は下がり始めている）。ズレの正体はほぼ**12〜13ヶ月の転嫁ラグ**です。

### 数字の突き合わせ

**国際相場（ICO 総合指標価格 I-CIP、US cents/lb）**

| 時期 | I-CIP |
|---|---|
| 2025年2月 | **354.32**（月次で史上最高） |
| 2025年11月 | **330.44**（二番天井） |
| 2025年12月 | 304.68（前月比 −7.8%） |
| 2026年1月 | 296.89（−2.6%） |
| 2026年4月 | 266.24（−2.7%） |
| 2026年5月 | 256.05（−3.8%） |
| 2026年6月 | **248.90**（−2.8%）※6/9に231.96まで下げ約2年ぶり安値、月末272.39へ反発 |

→ ピークは正確には2025年2月ですが、2025年後半にもう一度330台まで戻した「二番天井」があるので、聞いた話はおおむね合っています。ピークからは**約3割下落**。

**日本の店頭（総務省CPI「コーヒー豆」、2020年=100）**

- 前年比のピーク：2025年9月 **+64.1%**
- 指数の水準ピーク：2026年3月 **261.8**
- 直近：**238.5、前年比+23.3%**（2026年6月分。※出典記事によって「7月」表記の揺れあり＝下記「未確認」参照）

→ つまり**水準は2026年3月で頭を打ち、以降は下落中**。ただし前年比は依然+23%なので「この1年でやたら上がった」という体感は完全に正しいです。

**ズレの幅**：国際相場ピーク（2025年11月の二番天井）→ 日本CPIピーク（2026年3月）で**約4ヶ月**、真の天井（2025年2月）から数えれば**13ヶ月**。

## 仮説（確からしい順）

順序の基準は「①タイミングが実データと整合するか ②因果メカニズムが観測可能な形で存在するか ③どれだけの値幅を説明できるか」の3点です。上位2つは既に一次資料で裏が取れている、下位ほど推測が混じります。

### H1. 転嫁ラグ（在庫・先物ヘッジ・年間契約・値上げの発表→実施リードタイム）— 主因

焙煎業者は数ヶ月分の生豆在庫と先物ヘッジを持ち、契約も年単位。さらに値上げは「発表→出荷価格改定→店頭反映」で数ヶ月かかります。実例：**UCCは2025年12月22日に発表 → 2026年3月1日出荷分から改定**（店頭実質10〜18%上昇見込み）。キーコーヒーも2025年12月12日発表 → 2026年3月1日納品分。**つまり2026年3月の店頭値上げは2025年秋の相場を見て決められたもの**で、その後の下落は織り込みようがない。

**反証方法**：I-CIP を6〜15ヶ月ラグさせて日本CPIコーヒー豆との相関を取る。ラグ12ヶ月前後で相関が最大化すればラグ説。逆に、**どのラグでも相関が説明力を持たない、あるいは今後もCPIが上がり続けてピークアウトしない**なら、この仮説は否定される。現時点では「CPIが2026年3月でピークアウトした」という事実自体が強い支持証拠です。

### H2. 円建てでは下がり幅が目減りしている（為替）— 有力な副因

ドル建て −30% でも、日本の輸入業者が払うのは円。ドル円は2026年8月時点で **155〜159円台**（7月末の日米協調介入後に155円台→159円台へ反発）で高止まり。ドル建て下落の相当部分が円安で相殺されます。

**反証方法**：財務省貿易統計（HS 0901 生豆）の**月次・円建て輸入単価**を取り、ドル建て I-CIP と重ねる。円建て単価もドル建てとほぼ同時期・同率で下がっていれば為替の寄与は小さく、H2は主因から外れる。逆に円建て単価が横ばい〜微減にとどまっていれば支持。

### H3. 「相場」が一様に下がっていない（銘柄構成のズレ）

I-CIP は4指標の合成。2026年6月時点で **Colombian Milds は 324.60（前月比+0.4%）、Other Milds は 307.83（−2.4%）** と、高級アラビカは総合指数ほど下がっていない。日本の家庭用レギュラーコーヒーはアラビカ中心なので、「総合指数の下落」を自分の買う豆に当てはめると過大評価になります。

**反証方法**：ICO の4指標別系列を個別に見る。Colombian Milds / Other Milds も総合と同率で下落していれば、この仮説は消える。

### H4. 生豆以外のコストが下がっていない（人件費・物流・電力・包装・焙煎）

小売価格に占める生豆比率は100%ではない。相場が3割下がっても店頭が3割下がることはない。

**反証方法**：企業物価指数の「飲食料品」や、生豆比率が低い加工品（缶コーヒー、インスタント）と、生豆比率が高いレギュラーコーヒー豆のCPIを比較。両者の下落タイミング・幅に差がなければ、生豆以外のコストは主要な説明要因ではない。

### H5. 価格の下方硬直性／マージン回復（"rockets and feathers"）

上がるときは速く、下がるときは遅い、という一般的な非対称性。2024〜25年に逆ザヤを飲んだ分をここで回収している可能性。

**反証方法**：過去の相場高騰局面（2011年ピーク → 2013年暴落）で、日本のCPIコーヒー豆が下落に転じるまでの遅れを測る。上げ局面のラグと下げ局面のラグがほぼ同じなら、非対称性＝この仮説は成立しない。H1（対称なラグ）で十分説明がつく。順位が下なのは、H1と観測上ほぼ区別できず、切り分けにこの過去データ比較が必須だから。

### H6. 実質値上げ（内容量減・グレード変更）

200g→180gや、ブレンド比率の変更。CPIは品質調整をかけるので、体感の「1袋の値段」とCPIがズレる。

**反証方法**：小売物価統計調査の **100gあたり平均価格**（2026年2月時点で47都市平均 351円/100g）を時系列で追う。100g単価がCPI指数と同じ動きをしていれば、内容量調整は主因ではない。

### H7. 観測バイアス（自分の購買行動の変化）

買う店・銘柄がスペシャルティ寄りにシフトしていれば、統計以上に上がって見える。最下位なのは、これだけでは+23%という統計上の全国平均を説明できないため。

**反証方法**：自分の購買記録から「同一銘柄・同一店・同一容量」の価格だけを抜き出して時系列化し、CPIと比べる。一致すれば統計どおりで、バイアスなし。

## 一番効率のいい検証手順

1. **総務省CPI「コーヒー豆」の月次指数**を e-Stat から直接取る（2024年1月〜最新）
2. **ICO I-CIP の月次系列**を重ねる
3. **財務省貿易統計の円建て生豆輸入単価**を第3の線として重ねる

この3本を並べれば、H1・H2・H3はほぼ一発で切り分けられます。予想としては「円建て輸入単価がI-CIPより数ヶ月遅れ・浅く下落し、CPIがさらに数ヶ月遅れて追随」という三段階になるはずです。
