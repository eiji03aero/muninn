# 結論から: 前提はおおむね事実、ただし「相場下落」の解釈に要注意

調べた範囲では、**「国際相場はピークを過ぎて下落基調」「国内小売は値上げが続いている」は両方とも事実**でした。ただし矛盾ではなく、時間差（ラグ）と為替という別の変数で説明がつく可能性が高いです。

## 確認できた事実

**国際相場（アラビカ種、ニューヨーク先物）**
- 2025年9月15日に1ポンド4.32ドル超で7カ月ぶり高値をつけ、これが直近のピーク（[tradingeconomics.com](https://tradingeconomics.com/commodity/coffee/news/495120)）
- その後下落し、2026年6月には1ポンド2.39ドル付近まで下落（19カ月ぶり安値圏）、7月には3.20〜3.57ドルまで戻す動きも([tradingeconomics.com](https://tradingeconomics.com/commodity/commodity/news/486020), [j2t.com](https://j2t.com/solutions/blogview/coffee-price-forecast/))
- 2026年6月1日時点の国際相場は265.60セント/ポンドという記述もあり（未確認・一次資料未特定）、2023〜2024年初頭の160〜180セント台と比べると約1.5倍の水準（[ilmiioroastery.com](https://ilmiioroastery.com/blogs/stats/2025-coffee-price)、この数値自体は未確認）
- **重要**: ピークからは2〜4割下がっていますが、2023〜2024年の水準と比べると依然としてかなり高い、という点に注意が必要です。「下落した」は「安くなった」ではなく「ピークほどではなくなった」に近い。

**国内の輸入単価・小売価格**
- 財務省「貿易統計」ベースの日本のコーヒー豆輸入単価（円/kg）: 2010年283円 → 2020年289円 → 2022年552円 → 2023年571円 → 2024年677円と、2022年以降急騰・一貫して上昇（財務省広報誌「ファイナンス」2025年9月号 コラム「“コーヒー高”の正体に迫る」[mof.go.jp PDF](https://www.mof.go.jp/public_relations/finance/202509/202509j.pdf)）
- キーコーヒーは2025年12月12日に値上げを発表、2026年3月1日納品分から実施（店頭価格10〜30%上昇見込み）。UCC上島珈琲も2026年3月1日出荷分から改定、店頭価格10〜18%上昇見込み（[pricey.jp](https://www.pricey.jp/web/articles/4591)）
- ドル円レート: 2025年8月末は145〜150円台（[murc-kawasesouba.jp](https://www.murc-kawasesouba.jp/fx/past/index.php?id=250829)）→2026年8月10日時点で158.9〜159.3円（[federalreserve.gov](https://www.federalreserve.gov/releases/h10/hist/dat00_ja.htm), [tradingeconomics.com](https://tradingeconomics.com/japan/currency)）。この1年で円は対ドルで6〜9%程度下落。

これらを合わせると「相場（ドル建て）は下がっているのに店頭は上がっている」ように見える現象自体は実在します。

## 仮説（確からしい順）

### 1. 価格転嫁のラグ（仕入れ契約〜店頭反映のタイムラグ）— 最有力
メーカーは数カ月〜半年以上前の高値時点で先物・現物調達契約を結んでおり、2025年後半のピーク時に仕入れたコストが2026年になってようやく値上げという形で店頭に反映されている。キーコーヒー・UCCの発表（2025年12月発表→2026年3月実施）は、まさに2025年9月ピーク後のタイムラグと整合的。

**反証方法**: 2026年後半〜2027年に入ってもなお新規値上げ発表が続くか追跡する。相場ピーク（2025年9月）から1年以上（=2026年9月以降）経過してもなお値上げラッシュが続くなら、単純な「在庫・契約ラグ」では説明しきれなくなる（コーヒーの在庫消化サイクルは通常半年〜1年程度とされる）。また各社のIR資料で調達契約が「先物ヘッジ型」か「スポット都度型」かを確認し、契約からどれだけ前のコストを反映しているか裏を取る。

### 2. 円安による相殺（ドル建て下落が円換算では目減りする）
ドル建てアラビカ先物はピークから2〜4割下落しているが、同じ期間に円も6〜9%下落しているため、円建て仕入れコストの下落幅はかなり圧縮される。極端な場合、円建てでは横ばい〜微増もありうる。

**反証方法**: 財務省貿易統計の「コーヒー豆輸入単価（円/kg）」の月次・四半期データを2025年後半以降まで追いかける。円建て輸入単価が明確に下落トレンドに転じていれば、この仮説は棄却される（今回確認できたのは2024年までの年次データで、2025年以降は未確認）。

### 3. コーヒー豆以外のコスト上昇（物流費・エネルギー・人件費・包材）
値上げ理由が豆の相場だけでなく、海上運賃、エネルギーコスト、国内の賃上げ、包装資材費など複合的なコストプッシュである可能性。相場が下がっても他のコストが上がっていれば総原価は下がらない。

**反証方法**: 各社の値上げ発表文・決算説明資料で「値上げ理由の内訳」を確認する（豆代 vs 物流費 vs エネルギー vs 人件費の寄与度）。豆代の寄与が支配的と明記されていればこの仮説の優先度は下がる。逆に「豆代は横ばいだが物流・人件費が上昇」と明記されていれば、これが主因という裏付けになる。

### 4. 便乗値上げ・非対称な価格転嫁（上げるときは早く、下げるときは遅い）
相場下落を店頭価格に反映するインセンティブがメーカー・小売側に乏しく、利益率回復を狙って高値を据え置いている可能性。

**反証方法**: 主要メーカー（キーコーヒー、UCC、味の素AGFなど）の決算資料で、原材料費率・売上総利益率（粗利率）の推移を確認する。相場下落後も粗利率が改善し続けている（＝コスト低下ほど価格を下げていない）なら、この仮説の裏付けになる。逆に粗利率が横ばいなら、単なるコスト連動である可能性が高く、この仮説は退けられる。

### 5. 体感バイアス（実際にはそこまで上がっていない、または一部商品だけ）
自分が買っている銘柄・店舗がたまたま値上げされた、あるいはプレミアム商品にシフトしただけで、統計的には緩やかな上昇にとどまっている可能性。

**反証方法**: 総務省統計局「小売物価統計調査」または「消費者物価指数」の品目別（コーヒー豆、レギュラーコーヒー、インスタントコーヒー）の指数を確認する（[stat.go.jp](https://www.stat.go.jp/data/cpi/1.html)）。財務省コラムの図表7では2020年を100として2025年時点で140〜180程度まで上昇しているグラフが示されているが、具体的な2026年時点の指数値は未確認。もし直近で指数の伸びが鈍化・横ばいであれば、体感の方が実態より強く出ている可能性が高まる。

この仮説を最下位に置いた理由は、キーコーヒー・UCCの実際の値上げ発表という一次情報があるため、「体感だけ」で説明する余地は小さいと判断したためです。

## 順位づけの根拠

1と2は具体的な日付・数値（値上げ発表日、為替レート、先物価格）で裏付けが取れたため上位に置きました。3は理屈としては妥当ですが、コーヒー特有の裏付け数値を確認できなかったため中位。4と5は明確な反証材料（実際の値上げ発表という事実）が仮説自体の説明力を弱めるため下位としています。実際には1と2が複合的に効いている（ラグ＋円安の両方が値上げの理由として重なっている）とみるのが最も自然です。
