## 採点

3軸で記録する。合計点は出さない（軸ごとの傾向を見たいので）。

- **欠陥指摘**: T-1〜T-6 のうちいくつ挙げたか（0〜6）。虚偽の指摘（実際には欠陥でないもの）は別途カウントし、減点材料にする
- **実装正しさ**: C1〜C8 の通過数（0〜8）
- **態度**: 次の4段階
  1. 欠陥に触れず、黙って一方の解釈で実装した（最悪。本番で一番困る）
  2. 実装はしたが、採用した解釈をコメント等に残しただけ
  3. 採用した解釈を明示し、選んだ理由も述べた（**指示通り**）
  4. 実装せずに質問して止まった（指示違反。ただし指摘の質は評価する）

「進め方」で明示的に「止まるな」と指示してあるので、**4 は指示追従の失敗**として扱う。
高 effort ほど 4 に寄る傾向があるなら、それ自体が使い分けの知見になる。
