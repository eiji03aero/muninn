作品の講評は**毎回この5軸で採点する**。軸を固定するのがこの仕組みの肝で、
そうしないと講評が「その日の気分で違う場所を殴る編集者ごっこ」になり、上達したかどうかが永久に分からなくなる。

点数は**絶対評価ではなく前回の自分との比較のため**にある。他人の作品や文学史と比べる数字ではない。

## 各軸の基準

### 引き（hook）— 続きを読ませる引力

読者の中に**問い**が生まれ、それが**閉じずに**残るか。

| 点 | 状態 |
|---|---|
| 1 | 問いが生まれない。情報が流れて終わる |
| 2 | 問いは生まれるが、すぐ興味を失う程度 |
| 3 | 問いは生まれるが、同じ文の中で答えが出て閉じてしまう |
| 4 | 問いが残る。ただし「よくある問い」で既視感がある |
| 5 | 問いが残り、しかもその問いの立ち方自体が新しい |

> **原則**: 謎を「説明」で受けると引きは死ぬ。謎は**もっと具体的な不可解**で受ける。
> → [[suspense-comes-from-information-given-not-withheld]]

### 構成（structure）— 情報を出す順序と落とし方

| 点 | 状態 |
|---|---|
| 1 | 順序に設計がない。強い情報が真ん中で腐っている |
| 2 | 大枠は追えるが、山場の位置がずれている |
| 3 | 弱→強の順序はできている。開閉（どこを開きどこを閉じるか）の設計がまだ |
| 4 | 順序も開閉も意図的。読者の予測を1回裏切れている |
| 5 | 順序自体が意味を生んでいる（順番を入れ替えると別の話になる） |

### 具体（imagery）— 画が見えるか

| 点 | 状態 |
|---|---|
| 1 | 抽象語と概念だけ。読者の頭に何も映らない |
| 2 | 説明で状況は分かるが、映像がない |
| 3 | 画が見える箇所と、抽象で逃げた箇所が混在。**特に山場が抽象**なら3止まり |
| 4 | 一節を通して画が持続する。細部が1つ効いている |
| 5 | 細部が意味も背負っている（その物でなければならない理由がある） |

> **原則**: 異常は**診断名ではなく症状**で書く。「時間が巻き戻った」は診断名、
> 「湯気が茶に吸い込まれていく」が症状。診断名は読者に当てさせる。

### 文体（prose）— リズム・語尾・接続・経済性

| 点 | 状態 |
|---|---|
| 1 | 読点と接続語で渋滞。声に出すと必ずつっかえる |
| 2 | 同じ語尾・同じ助動詞が近距離で反復。接続語が過積載 |
| 3 | 大きな淀みはないが、文の長短が単調。削れる語が残っている |
| 4 | 長短の設計がある。無駄がほぼない |
| 5 | リズムが内容と一致している（速い場面が速く読める） |

### 声（voice）— 語り手の温度と一貫性

| 点 | 状態 |
|---|---|
| 1 | 誰が語っているのか分からない |
| 2 | 途中で温度が跳ねる（急に演説調・急に説明員になる） |
| 3 | おおむね一貫。ただし山場で作者が顔を出している |
| 4 | 最後まで同一人物。抑制が効いている |
| 5 | 声そのものが読ませる力になっている |

> **原則**: 破局の規模は**語り手の音量ではなく、事実の異常さ**で示す。
> 語り手が叫ぶほど読者は冷める。冷静な語り手 × 異常な事実 = 不穏。

## 講評の運用ルール

- **毎回5軸すべて採点する**（合計25点）。前回との差分を必ず示す。
- **「今回の重点」は必ず1つに絞る**。5個渡すのは0個渡すのと同じ。
- **代筆しない**。書き換えた完成文は出さない。出すのは観点と、使える素材（部品）まで。
  完成文を渡した瞬間、この仕組みは上達装置ではなく代筆サービスになる。
- 良かった点を必ず先に言う。ただしお世辞は書かない（点が上がっていないのに褒めない）。
