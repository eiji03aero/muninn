「9時まで**上体の回転だけ**で上げるべき」は**ドリル/誇張であって絶対ではない**。実際のテークバックは **体の回転＋腕＋"自然でゆるやかな手首のセット（コック）＋前腕の回旋"のブレンド**。**手首はバックで必ず折れる**（タメ＝パワーに必要）。「ワンピース/体だけ」は**"手を使いすぎる人"（早く内へ引く・腕を切り離す・こねる）への矯正の誇張**＝「ゼロにしろ」でなく「**手主導にするな**」の意味。

- ローリー等が「左手首を操作している」ように見えるのは、**誰にでもある自然なセット＋前腕回旋**（Feel≠Real、**意識的マニピュレーションと読み違えない**）。

**自分の実感**「手のイメージでアークを描いて上げるとスムーズ＆ミート率UP」は**良い感覚**で、記録済み「ハンズイン＋てこで自然に上げると再現性UP」と**一致**。滑らかな幅のあるアーク＋自然なセット→良いシーケンス→良い当たり。

**注意①（フェース）**: フェースを"ボールに向くよう"調整＝**被せ（シャット/ボウ）に注意**。9時の正解は**トウアップ／リーディングエッジが背骨と平行＝スクエア**。**フェースがボール（地面）を向く＝シャット**で、**フック寄り＋低打ち出しの自分には引っかけ＋低球**が増える。**トウアップ＝スクエアをキープ**（ボールに向けにいかない）。

**注意②（別物）**: これは**"滑らかな自然なセット"であって"タイミングを合わせる操作"ではない**。**始動の自然な手**と**ダウンの受動リリース**は別物（今日の失敗＝ダウンの操作＝キャストと混同しない）。
