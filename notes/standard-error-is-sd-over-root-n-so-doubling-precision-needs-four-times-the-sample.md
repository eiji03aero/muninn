標本平均の分布（標本分布）の標準偏差を**標準誤差（SE）**と呼び、その値は

**SE = SD / √n**

で与えられる。SD は母集団のばらつき、n は標本サイズ。分母が n ではなく **√n** であることが、統計でいちばん高くつく事実になる。

**精度を2倍にするには標本を4倍、10倍にするには100倍。** 調査費用はおおむね人数に比例するので、精度は費用の平方根でしか買えない。大規模調査がある規模で頭打ちになるのは、次の一桁が百倍の費用を要求するからである。

逆にこの式は「なぜ千人で国全体が言えるのか」に数量で答える。比率の推定では SE = √(p(1−p)/n) で、最悪の p=0.5 でも n=1,000 なら SE は約1.6%、その1.96倍で **±約3.1%**——世論調査の「誤差±3ポイント」の正体はこれだ。しかも式に**母集団の大きさ N が現れない**（N が n より十分大きければ有限母集団修正はほぼ1）。一億人の国でも十万人の町でも、千人なら同じ精度になる。

実務上の帰結として、**SE は常に SD より小さく、n を増やせばいくらでも縮む**。だからグラフのエラーバーに SD ではなく SE を使うと、ばらつきが小さいかのような印象を与えられてしまう。
